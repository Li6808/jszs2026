# 教师助手 · 在电脑上打开

## 一句话

**双击 `打开教师助手（Mac）.command`**（Windows 双击 `打开教师助手（Windows）.bat`），
会自动弹出一个黑色窗口、再自动打开浏览器。**那个黑色窗口别关**，用完再关。

数据存在你这台电脑的浏览器里，不联网也能用。

---

## ⚠️ 不要双击 `index.html`

试过的人都会踩这个坑：双击 `index.html` 之后浏览器一片空白。

**这不是文件坏了。** 是浏览器的安全规定：

- 这个应用是「模块化脚本」写的，浏览器**禁止**用 `file://` 方式加载它（本地文件的"来源"被当作空白，直接被拦）
- 就算绕过这一条，`file://` 方式下**数据也存不住**（Safari 会直接报错），等于白用

所以必须通过一个小服务（`http://127.0.0.1:...`）打开。上面那个双击脚本就是干这个的。

---

## 怎么用

1. 双击 `打开教师助手（Mac）.command`
2. 会弹出一个终端窗口，显示这样一段：

   ```
     📚 教师助手 · 已在你的电脑上打开
     ─────────────────────────────────────────
     地址      http://127.0.0.1:8790/
     数据位置  这个浏览器的本地存储里
     联网要求  不需要，断网照样用
   ```

3. 浏览器会自动打开这个地址。没自动打开的话，**手动把上面那个地址复制到浏览器**也行
4. 用完了，在那个终端窗口里按 **Control + C** 停止，然后关掉窗口

> 💡 电脑上装了 Node.js 的话速度更快；没装也没关系，会用系统自带的 Python 顶上。
> 两个都没有的情况极罕见（Mac 一定自带 Python）。

---

## 数据在哪？会不会丢？

数据存在**浏览器**里，关掉窗口、重启电脑都还在。

但要留意：**换个浏览器打开，数据就不在了**（比如今天用 Safari、明天用 Chrome，是两个互不相通的地方）。
**建议固定用同一个浏览器。**

想换电脑带走数据：

> 应用里进「个人设置 → 数据备份」→ 导出，得到一个 `.json` 文件
> 在新电脑上双击启动 → 「数据备份」→ 导入这个文件

备份是**全量**的，一次导出就包含全部模块，不用逐个板块备份。

## 常见问题

**Q：双击后弹出「无法打开，因为它来自身份不明的开发者」？**
这是 macOS 的 Gatekeeper 拦截（文件是通过微信/网盘传过来的才会这样）。
**右键点这个文件 → 选「打开」→ 再点「打开」**，之后就不会再问了。

**Q：双击后窗口一闪就没了？**
说明启动失败。把这个目录完整拷贝（别只拷一个文件），确认 `_local-server.mjs`
和 `_local-server.py` 两个文件都在。

**Q：提示端口被占用？**
脚本会自己往后找空闲端口（8790 → 8791 → …），一般不用管。

**Q：手机上能用吗？**
这个包只能在这台电脑上用。想要手机也能用、数据还存在电脑上，
请用另一个包「**教师助手_自己电脑做服务器**」。

**Q：想分享给别的老师？**
最省事的是直接给线上地址，别人点开就用、不用装任何东西：

> https://li6808.github.io/jszs2026/

## 这个目录里都是什么

| 文件 | 作用 |
|---|---|
| `打开教师助手（Mac）.command` | **双击这个**（Mac） |
| `打开教师助手（Windows）.bat` | **双击这个**（Windows） |
| `index.html`、`assets/` | 应用本体，**不要直接双击** |
| `_local-server.mjs` / `_local-server.py` | 起本地服务的小程序，不用管它 |
| `manifest.json`、各 `pwa-icon-*.png` | 图标与安装配置 |
