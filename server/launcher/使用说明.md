# 教师助手 · 自己电脑当服务器

**一句话**：在自己电脑上跑一个小服务，数据集中存在这台电脑上；
手机连上同一个 Wi-Fi 就能打开同一个应用，换手机扫码 + 登录就能把数据找回来。

---

## 先看这里：你需不需要它？

| 你的情况 | 建议 |
|---|---|
| 只在一台设备上用（就这台手机 / 就这台电脑） | **不需要**。用普通版本就行，靠「💾 数据备份与恢复」定期导出备份即可 |
| 手机和电脑都要用，希望是同一份数据 | ✅ 用它 |
| 两三位老师共用一台电脑上的同一份班级数据 | ✅ 用它 |
| 想让同事在外面（不同网络）也能访问 | ❌ 这个包不行，得放公网服务器，见文末 |

> ⚠️ 一个必须提前说清楚的限制：**这个方案只在同一个 Wi-Fi 下可用**。
> 电脑关机、睡眠、合盖，或者关掉那个黑色窗口，手机就打不开了。

---

## 一、第一次使用（只做一次）

### 第 1 步：装 Node.js

电脑上得先有 Node.js，这个服务才能跑。

打开官网 <https://nodejs.org> → 下载 **LTS 版本** → 一路「下一步 / 继续」装完。

装完**不用做任何设置**，也不用打开它。

### 第 2 步：启动服务

- **Windows**：双击 `启动服务器（Windows）.bat`
- **Mac**：双击 `启动服务器（Mac）.command`

会弹出一个**黑色的命令窗口**，里面写着类似这样的内容：

```
  📚 教师助手 · 自己电脑当服务器（手机可接入）
  ─────────────────────────────────────────
  本机访问  http://127.0.0.1:8787
  局域网    http://192.168.1.8:8787
  数据目录  D:\...\教师助手_自己电脑做服务器\data
  静态托管  D:\...\教师助手_自己电脑做服务器\www
  注册状态  开启（需邀请码）
  邀请码    js-5144570d
  单包上限  24 MB

  📱 手机同步怎么用：
     1. 手机连上和这台电脑【同一个 Wi-Fi】
     2. 手机浏览器打开上面那个【局域网】地址
     3. 在应用里注册账号，然后点「上传当前全部数据到服务器」
```

**🔴 这个黑窗口就是服务器，别关它。** 最小化可以，关掉手机就连不上了。

> 首次启动会自动生成一个**邀请码**（形如 `js-5144570d`），保存在 `server/config.json` 里，
> **每次启动都会打印在上面那个窗口里**（就是「邀请码」那一行）。
> 手机上注册账号时要把这串填进去。窗口不小心关了？用记事本打开 `server/config.json` 也能看到。

### 第 3 步：在电脑上打开应用

启动后浏览器会**自动打开**。如果没打开，手动在浏览器地址栏输入上面那个
**局域网**地址（形如 `http://192.168.1.8:8787`）。

然后：

1. 进「👤 我的」→「🔌 数据存放方式」
2. 应该会看到绿色的「🎯 检测到本机服务器」→ 点 **「✅ 就用这台服务器」**
3. 切到 **「注册新账号」** → 填账号、密码、邀请码（黑窗口里有）→ 注册
4. 点 **「☁️ 上传当前全部数据到服务器」**

到这一步，电脑这边就好了。

### 第 4 步：让手机也连上

1. 手机连上**和电脑同一个 Wi-Fi**（重要：同一个路由器，不是流量）
2. 在应用的「🔌 数据存放方式」里点 **「📱 手机扫码打开」**，用手机相机/微信扫码
3. 手机上打开后，同样进「🔌 数据存放方式」→「✅ 就用这台服务器」
   （手机上会自动填好地址，不用手输）
4. 用**同一个账号登录** → 点 **「⬇️ 从云端拉取」**（选「合并」）

数据就同步到手机上了。

## 二、日常怎么用

**每次使用前**：
1. 双击启动脚本（黑窗口留着别关）
2. 手机连同一个 Wi-Fi，打开应用（建议把地址存到浏览器书签/加到桌面）

**改完数据想同步**：进「🔌 数据存放方式」→ 点「☁️ 上传当前全部数据到服务器」。
手机上想看最新：点「⬇️ 从云端拉取」。

**用完**：黑窗口里按 `Control + C`，或者直接关掉窗口。
（数据已经存在电脑上，关掉不会丢。）

> 💡 小技巧：可以在电脑上把 `http://127.0.0.1:8787` 存成浏览器书签，
> 以后一键打开，不用再找地址。

## 三、数据存在哪？换电脑怎么办？

全部数据都在 **`data` 文件夹**里：

```
教师助手_自己电脑做服务器/
└── data/
    ├── users.json      账号信息（密码是加密存储的，不是明文）
    ├── sessions.json   登录状态
    └── blobs/          每位老师的完整数据包
```

**换电脑 / 备份＝把整个文件夹拷走。**

拷到新电脑后，重新装一下 Node.js，双击启动脚本，一切照旧。
数据文件是纯文本 JSON，坏了也能用记事本打开看。

> 建议顺手也定期用应用里的「💾 数据备份与恢复」再导出一份 `.json`，
> 双重保险。

## 四、常见问题

### 双击后提示「无法验证开发者」（Mac）

这是从网上传过来的文件被系统拦了。解决：
**右键点那个 `.command` 文件 → 选「打开」→ 再点一次「打开」**。
之后就能正常双击了。

### 双击后没反应，或者提示「没有合适的访问权限」（Mac）

说明打包/传输时把「可执行」权限弄丢了。解决：
在这台电脑上打开「终端」App，输入 `chmod +x ` （**注意末尾有个空格**），
然后把那个 `.command` 文件**拖进终端窗口**，按回车。之后就能双击了。

### 提示「Windows 已保护你的电脑」（Windows）

点 **「更多信息」→「仍要运行」**。

### 提示「没找到 Node.js」

回第 1 步，去 <https://nodejs.org> 装一下 LTS 版本。装完**重开**一次启动脚本。

### 提示「端口 8787 已被占用」

多半是这个服务**已经在运行了**（看看有没有别的黑窗口开着）。
也可以换一个端口：在黑窗口里按 Ctrl+C 停掉，然后手动运行：

```
node server/start.mjs --lan --port 8788
```

（换端口后，手机上的地址也要跟着换成 `:8788`。）

### 手机打不开

按顺序检查：

1. 电脑上的黑窗口还开着吗？
2. 手机和电脑是**同一个 Wi-Fi** 吗？（不是手机流量，也不是「Wi-Fi 5G / 2.4G 不同网段」）
3. 地址是不是 `http://192.168.x.x:8787`（**http** 不是 https；IP 要和黑窗口里显示的一致）？
4. 电脑上装了防火墙/安全软件吗？放行一下，或临时关掉试试。
5. 公司/学校的 Wi-Fi 常常做了「客户端隔离」，手机和电脑互相看不到 ——
   换一个手机热点试试，如果热点下能用，就是网络隔离的问题。

### 忘记密码了

删掉 `data/users.json` 里对应的那条记录重新注册（会影响该账号已有的数据包关联），
或者直接把 `data/users.json` 删掉全部重新注册。**删之前先把 `data` 文件夹备份一份。**

### 电脑上能看到数据，手机上拉取后看不到

拉取时选了「合并」，本机原有记录会保留、云端独有的会追加。
如果两边记录对不上，可以选「覆盖」——但**覆盖会把本机那份整体替换掉，不可撤销**，
操作前先导出一份备份。

## 五、想在公网用（同事在外网也能访问）

这个包**只适合局域网**。如果要放公网，需要：

1. 一台有公网 IP 的云服务器（约 ¥38~300/年）
2. 配 HTTPS 反向代理（**这步不能省** —— 不配的话密码是明文在网上传）
3. 详细步骤见同目录/项目里的 `server/README.md`

⚠️ **合规提醒**：学生真实姓名属于个人信息。放到公网服务器上，
至少要保证「HTTPS + 账号鉴权 + 关闭匿名注册」三样都做到。

## 六、技术细节（不看也行）

- 服务端零第三方依赖，只用 Node.js 内置模块，不需要 `npm install`
- 接口都在 `/api/` 下：`/api/health`（健康检查）、`/api/register`、`/api/login`、
  `/api/blob`（上传/下载整包数据）、`/api/admin/users`（管理员汇总）
- 密码用 `scrypt` 加盐哈希存储，登录令牌是随机的，有过期时间
- 上传/下载的是**整份数据包**（和你手动导出的 `.json` 备份格式完全一致），
  所以就算服务器哪天不用了，拿到的备份文件也能直接导回应用
- 默认单包上限 24 MB，注册有频率限制

**手动启动命令**（不想用脚本时）：

```bash
# 局域网模式（自动生成邀请码、托管前端、打开浏览器）
node server/start.mjs --lan --static-dir www --data-dir data

# 只监听本机（别人访问不到，自己电脑上用）
node server/start.mjs --static-dir www --data-dir data

# 查看所有参数
node server/start.mjs --help
```
