# 换图标 · 说明

这个文件夹是给你**自己换应用图标**用的，不用改代码、不用重新构建。

---

## 怎么换（Mac）

1. 准备一张**正方形**图片，命名成 **`我的图标.png`**（jpg 也行，叫 `我的图标.jpg`），
   放进**本文件夹**（和这个说明文件放一起）
2. 双击 **`换图标（Mac）.command`**
3. 出现「完成！」就成功了。手机上要看到新图标，还得再做一次：

   **长按主屏幕上旧图标 → 删除 → 用 Safari 重新打开应用 → 分享 → 添加到主屏幕**

   （已经装好的图标不会自动变 —— 系统在「添加到主屏幕」那一刻就把图标存下来了）

---

## 图片有什么要求

| 要求 | 说明 |
|---|---|
| **正方形** | 不是正方形的话，脚本会居中裁成正方形，可能裁掉你要的部分 |
| **满格、不带背景** | 你的图本身就该是一整块图标。如果四周有背景、白边、阴影、水印，会原样出现在图标四角 |
| **建议 512×512 以上** | 太小的话放大后会糊。1024×1024 最好 |
| PNG 或 JPG | 其它格式（webp/heic）不一定认 |

> ⚠️ 如果你用的是 AI 生成的那种图（一块圆角图标 + 周围一圈背景），**别直接放进来** ——
> 角落会露背景。那种图发给我，我帮你切干净。

## 换了之后会动到哪些文件

脚本会自动找到应用目录（静态版是包根；「自己电脑做服务器」版是里面的 `www/`），
覆盖那 6 个图标文件：

| 文件 | 用途 | 尺寸 |
|---|---|---|
| `apple-touch-icon.png` | **iPhone / iPad 主屏图标**（最有用的一个） | 180 |
| `pwa-icon-192.png` | 安卓主屏图标、浏览器页签 | 192 |
| `pwa-icon-512.png` | 安卓高清图标、安装弹窗 | 512 |
| `pwa-icon-64.png` | 小尺寸场合 | 64 |
| `favicon-32.png` | 浏览器标签页那个小图标（已放大内容，小图才看得清） | 32 |
| `pwa-icon-maskable-512.png` | **安卓专用**：内容缩到 86%，四周用底色铺满（安卓会把图标裁成圆形/水滴） | 512 |

安卓那个底色默认是米色 `#FBF3E6`。想换颜色就编辑 `换图标（Mac）.command`，
改开头那行 `BG="FBF3E6"`。

## 几个常见问题

**Q：手机上还是旧图标？**
A：必须先删掉旧的再重新添加。iOS 缓存图标很顽固，光刷新网页没用。

**Q：在线版（`li6808.github.io/jszs2026`）会变吗？**
A：不会。这个脚本只改你**本地这个文件夹**里的图标。想让在线版也换，把图发我，我重新部署一次。

**Q：Windows 电脑怎么换？**
A：Windows 没有自带的命令行缩图工具。按上面的尺寸表，用「画图」或在线工具把你的图
分别导出成那 6 个尺寸，**文件名保持一致**，覆盖到应用目录里即可（`pwa-icon-maskable-512.png`
记得留一圈底色边距）。

**Q：换错了想还原？**
A：把包重新拷一份就行；线上那份始终是官方的图标，没被改过。
